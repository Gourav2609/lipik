# Translations

Lipik's screens are in English only for now (see "Voice and copy" in
[docs/DESIGN.md](docs/DESIGN.md)).

The files in `src/i18n/locales/` come from
[Handy](https://github.com/cjpais/Handy). Lipik still uses them for the menu
bar menu and for parts of the app it shares with Handy. To fix one of those
strings, send the change to Handy, or open an issue here if it only affects
Lipik.

A full translation of Lipik would first need its own screens (`src/flow/`)
moved to i18n keys. If you want to help with that, open an issue in this
repository's Issues before starting.
