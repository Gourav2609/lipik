Real names in Slack huddles, from Slack's own talking marker.

## What's new

- **Real names in Slack huddles.** Slack marks whoever is talking in a huddle. Lipik can now read that marker while it records a huddle and put each person's Slack name on their voice, even in a first meeting where nobody says a name. It reads only the huddle tiles, never messages, and keeps the names and times with the meeting on your Mac. Turn it on in **Settings → Meetings → Names from Slack huddles**. Keep the huddle on the desktop you're using: macOS can't read windows on another desktop.
- **Careful by design.** A voice is named only when Slack's marker clearly matches it for at least 10 seconds. Two people sharing one laptop, or a tile that matches two voices, stay as Speaker 1 and Speaker 2. Names you set yourself always win.

## Install or update

Easiest: paste this into Terminal and press Return. It installs or updates Lipik with no security warning:

```bash
curl -fsSL https://lipik.pages.dev/install.sh | sh
```

Or by hand:

1. Download **Lipik.dmg** below (Apple silicon, M1 and later) and drag **Lipik** into **Applications**, replacing the old one.
2. First time only: Lipik isn't signed with an Apple Developer ID yet, so macOS blocks the first launch.
   - **macOS 15 and later:** double-click Lipik, click **Done**, then **System Settings → Privacy & Security → Open Anyway**.
   - **macOS 14 and earlier:** right-click Lipik in Applications, choose **Open**, then **Open**.
3. Updating keeps your settings, history and permissions.
