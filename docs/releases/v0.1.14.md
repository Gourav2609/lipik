Better Hinglish dictation: fewer lines cut short, question marks, corrections, and a safer clean-up.

## What's new

- **Hinglish lines no longer cut short.** On macOS 26, when the English speech model kept only the English words of a Hindi sentence ("Yard staging server." for "Yaar, staging server phir se down hai, koi dekh sakta hai kya"), Lipik now uses Apple's transcript, which heard the whole line.
- **Question marks on Hinglish questions.** Questions like "Khana kha liya kya?" and "Deploy aaj ho jayega na?" now end with a question mark.
- **Hinglish corrections.** "Main paanch baje aaunga, nahi nahi, chhe baje" is now corrected even in a short dictation. A single "nahi", as in "ya nahi", is no longer treated as a correction.
- **Safer clean-up.** If the clean-up model leaves out a phrase you said, Lipik types your words instead of its reply.

## Install or update

Easiest: paste this into Terminal and press Return. It installs or updates Lipik with no security warning:

```bash
curl -fsSL https://lipik.pages.dev/install.sh | sh
```

Or by hand:

1. Download **Lipik.dmg** below (Apple silicon, M1 and later) and drag **Lipik** into **Applications**, replacing the old one.
2. First time only: Lipik isn't signed with an Apple Developer ID yet, so macOS blocks the first launch.
   - **macOS 15 and later:** double-click Lipik, click **Done**, then **System Settings → Privacy & Security → Open Anyway**.
   - **macOS 14 and earlier:** right-click Lipik in Applications, choose **Open**, then **Open**.
3. Updating keeps your settings, history and permissions.
