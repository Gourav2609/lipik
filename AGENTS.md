# AGENTS.md

Notes for AI coding assistants working in this repository.

Lipik is a macOS voice dictation app built with Tauri 2 (forked from the
upstream app credited in README.md): a Rust backend in `src-tauri/` and a
React + TypeScript frontend in `src/`.

## Commands

```bash
bun install
bun run tauri dev        # run the app
bun run tauri build      # release build (see docs/INSTALL.md for signing)
bun run lint             # ESLint
bun run format:check     # Prettier + cargo fmt
cd src-tauri && cargo test --lib
```

[BUILD.md](BUILD.md) has the setup details.

## Where things are

Backend (`src-tauri/src/`):

- `lib.rs`: app setup, plugins, managers, logging.
- `managers/`, `audio_toolkit/`: recording, voice activity detection, model
  download and transcription.
- `engine_supervisor/`: runs transcribe.cpp in a child process (the app's own
  executable started with a worker flag).
- `apple_speech/`: Apple's on-device dictation as a second engine (macOS 26+),
  through the Swift helper in `src-tauri/apple-speech/`.
- `textflow/`: dictionary, snippets, tone clean-up, rewrite shortcuts, notes
  and stats. The commands and events are in `textflow/CONTRACT.md`.
- `notetaker/`: meeting recording, live transcript and notes. See
  `notetaker/CONTRACT.md`.
- `pill.rs`, `overlay.rs`: the pill at the bottom of the screen.
- `settings.rs`: stored settings. `cli.rs`: command-line flags.

Frontend (`src/`):

- `flow/`: Lipik's main window, pages, settings and onboarding.
- `overlay/`: the pill window. `notepad/`: the meeting notes window.
- `bindings.ts`: generated by tauri-specta on a debug run. Don't edit it by
  hand.
- `components/`: older shared pieces (onboarding, shortcut inputs, What's
  New, notetaker inputs).

## Rules

- Follow [docs/DESIGN.md](docs/DESIGN.md) for anything people see, including
  its wording rules.
- Keep changes small and match the style of the file you are in.
- Speech and AI clean-up stay on the user's Mac by default. Don't add network
  calls the user did not set up.
- Run the checks above before opening a pull request, and fill in
  `.github/PULL_REQUEST_TEMPLATE.md`.
