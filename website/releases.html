Lipik 0.1.1

26 October 2026 On GitHub

Help setting up clean-up, and better advice when macOS blocks a shortcut.

What's new

  • Clean-up setup in onboarding. A new step checks for the free Ollama app and the clean-up model. If Ollama is missing, one button takes you to it; if the model is missing, one button downloads it (about 5 GB) with a progress bar and Cancel. You can skip it and set it up later in Settings → Meetings, which has the same buttons.
  • Better advice when macOS blocks a shortcut. When fn + Space stops working, Lipik now names the real cause, such as Terminal's Secure Keyboard Entry or a password manager in front, instead of always blaming the lock screen.
  • Plain qwen3:4b is flagged as too slow for dictation; use qwen3:4b-instruct or qwen3:8b.

Install or update

  1. Download Lipik.dmg below (Apple silicon, M1 and later) and drag Lipik into Applications, replacing the old one.
  2. First time only: Lipik isn't signed with an Apple Developer ID yet, so macOS blocks the first launch.
    macOS 15 and later: double-click Lipik, click Done, then System Settings → Privacy & Security → Open Anyway.
    macOS 14 and earlier: right-click Lipik in Applications, choose Open, then Open.
  3. Updating from 0.1.0 keeps your settings, history and permissions.

Lipik 0.1.0

26 October 2026 On GitHub

The first build of Lipik: hold fn, speak, and clean text is typed wherever your cursor is. Free, open source, and it runs on your Mac.

Install

  1. Download Lipik.dmg below (Apple silicon, M1 and later) and drag Lipik into Applications.
  2. Open it once. Lipik isn't signed with an Apple Developer ID yet, so macOS blocks the first launch:
    macOS 15 and later: double-click Lipik, click Done, then open System Settings → Privacy & Security, scroll down and click Open Anyway.
    macOS 14 and earlier: right-click Lipik in Applications, choose Open, then Open.
    If macOS says the app "is damaged", run xattr -dr com.apple.quarantine /Applications/Lipik.app in Terminal and open it again.
  3. Allow Microphone (so it can hear you) and Accessibility (so it can type into other apps and notice the fn key).
  4. Optional, for clean-up: install the free Ollama app and run ollama pull qwen3:8b (about 5 GB).

Without it, Lipik still types what you said and fixes "um", spoken punctuation, numbers, times and spoken emails with its built-in rules.

What's in it

  • Dictation in any app: hold fn, speak, let go. Hands-free with fn + Space.
  • Clean-up on your Mac: removes fillers, keeps your corrections ("four, no, five" → "5"), fixes punctuation, writes emails and times properly, and never adds words you didn't say.
  • Vocabulary, snippets, and a tone for each kind of app.
  • Meeting notes: record a call, get a transcript and a short summary.
  • English by default; free Whisper models cover 99 languages. Hinglish is in beta.
  • Works with Wi-Fi off. No account, no tracking.

Known limits

  • Apple silicon only. Intel Macs can build from source.
  • Not notarised by Apple yet, hence the first-open step above.
  • Hinglish recognition is still weak; it's the next thing being improved.
